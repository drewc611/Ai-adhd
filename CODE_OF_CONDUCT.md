# Code of conduct

Be direct about the work and decent to the people. Critique positions, not authors; the
whole repo is built on that distinction. No harassment, no discrimination, no personal
attacks, in issues, PRs, or recorded runs.

The maintainer may edit, remove, or reject contributions and comments that break this, and
may block repeat offenders. Report problems to the maintainer through a GitHub issue or,
if that is not appropriate, by email to the address on the maintainer's GitHub profile.
